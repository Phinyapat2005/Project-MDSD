# Personal Fashion Stylist App

แอปแนะนำการแต่งตัว มีหน้าโฮมแสดงชุดแนะนำ สถานที่แนะนำ และข้อมูลสัดส่วน

## เปิดใช้งาน

- ติดตั้ง dependencies: `npm install`
- รันโหมดพัฒนา: `npm run dev`
- สร้าง production build: `npm run build`
- รัน production: `npm run start`

## API

- `GET / PUT /api/profile`
- `GET / PUT /api/measurements`
- `GET /api/products`
- `GET / POST / PATCH /api/wardrobe`

ข้อมูลแอปจัดเก็บใน `data/app-database.json`
